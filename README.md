# Movie API 🎬

A simple **Spring Boot REST API** for managing movies/items.  
This project demonstrates basic CRUD operations using Spring Boot, Maven, and REST principles.

---

## 🚀 Features
- Create a new movie/item (POST)
- Retrieve all movies/items (GET)
- Simple REST API returning JSON
- Built using Spring Boot

---

## 🛠️ Technologies Used
- Java
- Spring Boot
- Maven
- REST API
- Tomcat (embedded)
